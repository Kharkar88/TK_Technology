# TK Technology

## 📌 Project Overview

TK Technology is an IT Training Institute Management System developed using Django.  
This project helps manage students, courses, trainers, payments, attendance, results, certificates, and placements through an admin dashboard.

## 🚀 Technologies Used

- Python
- Django
- MySQL
- HTML
- CSS
- Bootstrap
- JavaScript

## ✨ Features

### Admin Dashboard
- Dashboard overview
- Manage all institute activities

### Student Management
- Add students
- Edit student details
- Delete students
- Search students

### Course Management
- Add courses
- Update courses
- Delete courses
- Course listing

### Trainer Management
- Manage trainer details

### Payment Management
- Track student payments

### Attendance Management
- Manage student attendance records

### Result Management
- Add results
- Calculate percentage
- Display grades
- Pass/Fail status

### Certificate Management
- Manage student certificates

### Placement Management
- Add placement records
- Manage company details
